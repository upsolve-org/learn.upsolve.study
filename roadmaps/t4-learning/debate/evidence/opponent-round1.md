# Opponent round 1 evidence

The repository inventory contains debate artifacts only. No grading implementation, learner test or target-server benchmark exists. Proponent reasoning files were not read.

## Semantic grading
https://www.anthropic.com/research/towards-understanding-sycophancy-in-language-models reports sycophancy across five assistants and four free-form tasks. This is evidence of a failure class, not an error-rate estimate for Qwen. Separating state transitions from model outputs cannot independently establish correctness of the semantic observations used by those transitions. A rubric generated by the same model from the same source can preserve the same misunderstanding. Student self-confirmation does not supply subject-expert validation.

## Extraction
https://github.com/py-pdf/pypdf/blob/main/docs/user/extract-text.md documents PDF extraction ambiguities including tables, mathematical formulas and reading order. Selectable text is therefore insufficient as an admission test. A selected chapter still needs source-to-extraction inspection for supported content, and answerability checks for generated assessment items.

## Serving and preparation arithmetic
P4 budgets 250 output tokens per ordinary response. Four requests completing within 10 seconds require at least 100 aggregate output tokens per second, ignoring prefill and all overhead. This is a requirement calculation, not a measured T4 rate or a proposed service guarantee. Actual latency cannot be inferred from memory fit.

An illustrative chapter with 10 skills, three assessment items per skill and 250 output tokens per item/rubric/hint bundle consumes 7500 generated tokens before map/outline work and retries. Ten new chapters consume 75000 output tokens. At hypothetical aggregate decoding rates of 20 or 50 tokens/s, decoding alone takes 62.5 or 25 minutes. These rates are sensitivity scenarios, not GPU predictions. Admission quotas, cancellation, reuse and interactive priority are needed even if prep is asynchronous.

## Human review estimate
An initial set of 200 labelled student responses at three minutes each costs 10 expert hours. Reviewing one 10-item sample for each of 100 uploaded chapters at two minutes per item costs 33.3 hours. These examples illustrate workload only; no upload rate or reviewer availability was specified. Subject/age/language diversity requires new coverage and expertise. An engineering-week estimate cannot absorb unassigned subject review by implication.

## First session
P1 and P3 together put extraction, outline confirmation, chapter selection, skill mapping and diagnostic work before ordinary teaching. The probability of abandonment is unknown without student usability testing. A preview lesson on a short selected excerpt can preserve the tutor goal while exposing whether students can start independently on a phone.

## Trust boundaries
https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html describes indirect injection, retrieval poisoning and layered defenses. Treating imported text as data is a policy intention, not a guaranteed model behavior. Account ownership must constrain retrieval before model invocation; model text must not control authorization or durable mastery updates. This is an implementation requirement, not a claim that current nonexistent code is vulnerable.
