# Choosing the next teaching step

Start with a fact the learner can already explain. If a later step depends on an uncertain prerequisite, check that prerequisite first. Use a precise definition when it helps. State any assumption the conclusion depends on.

Choose a concrete problem where the next idea is useful. Let the learner try one inference, then use their answer to decide what needs explaining. For example, if they understand that a branch points to a commit, they can predict what happens to that pointer after another commit.

Use these principles to choose questions privately. In the conversation, use the vocabulary of the subject. Give a derivation when the learner asks for one or when a missed step needs it.
